• List all environments: conda env list (or conda info --envs)
• See active environment info: conda info

• Create an empty environment: conda create --name myenv
• Create with a specific Python version: conda create --name myenv python=3.10
• Create with specific packages: conda create --name myenv python=3.10 numpy pandas

• Activate an environment: conda activate myenv
• Deactivate the current environment: conda deactivate

• List installed packages: conda list (adds -n myenv to see packages for a specific environment)
• Install a package: conda install package_name
• Remove a package: conda remove package_name
